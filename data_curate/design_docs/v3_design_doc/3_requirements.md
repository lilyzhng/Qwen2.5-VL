# 3. Requirements

## **3.1 Required for Approval**

The VLM Judge system must demonstrate:

- [ ] **Rejection Rate Reduction:** >50% reduction in iMerit human rejection rate averaged across test scenarios
- [ ] **Precision@100:** >80% precision on top-100 candidates for user-defined scenarios  
- [ ] **Precision Improvement:** >20% improvement over baseline score calibration
- [ ] **No Catastrophic Recall Loss:** VLM should not filter out >10% of true positives that humans would accept

## **3.2 Good-to-Have**

- [ ] **Cost Savings:** Reduce human review time by 40-60% through VLM pre-filtering
- [ ] **Explainability:** VLM explanations (observation + reason fields) help reviewers understand decisions
